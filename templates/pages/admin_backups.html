What restoring actually does

A restore replays the backup into the current database. It re-creates everything the backup contains, which makes it exactly right for recovering an empty or damaged database.

It is not an undo button: records created after the backup was taken are not removed by replaying an older copy. If you need a true point-in-time rollback, restore into a fresh, empty database and repoint the app at it.

Uploaded documents live in object storage, not the database, so they are unaffected by a restore either way.
