Maintenance mode

{% if maintenance_on %} ON — visitors see the maintenance page {% else %} Off — app is live {% endif %}

Flip this on before a database restore or a server move. Everyone gets a calm "back in a few minutes" page instead of errors, search engines are told it's temporary, and nothing can write to the database mid-restore. The marketing site, the login page, and this admin area stay reachable so you can turn it back off when you're done.

Scheduled-maintenance notice

{% if !notice.is_empty() %} Showing to all signed-in users {% endif %}

A banner shown at the top of every signed-in page. Use it a day or two ahead of planned work so nobody is surprised. Keep it short and say when, for how long, and that no action is needed. For example: "TransactVault will be offline Saturday from 9 to 10 pm Pacific for scheduled maintenance. Nothing is required from you."
